# Renderer Package Documentation (`renderer/renderer.go`)

## Overview

The `renderer` package provides a generic framework for rendering Abstract Syntax Tree (AST) nodes generated by `goldmark` into target formats (e.g., HTML, Text, etc.).

It defines abstractions for context management during rendering, node-specific renderers, renderer decorators, configuration options, and a generic execution engine (`Helper`) that walks the AST and coordinates output generation.

---

## Key Interfaces and Types

### Context Management

#### `ContextKey` & `NewContextKey`
* **`type ContextKey int`**: A unique identifier key used to store and retrieve arbitrary state within a rendering context.
* **`func NewContextKey() ContextKey`**: Generates and returns a globally incremental `ContextKey`.

#### `Context` Interface
Holds state and rendering configuration during the execution of a render job.
```go
type Context interface {
    Get(ContextKey) any
    ComputeIfAbsent(ContextKey, func() any) any
    Set(ContextKey, any)
    Render(w any, source []byte, n ast.Node) error
    Clone() Context
}
```

#### `renderContext` Struct & `NewContext`
The standard implementation of `Context`. It uses a slice (`store`) indexed by `ContextKey` to achieve fast lookup times.
* **`NewContext(opts ...ContextOption) Context`**: Instantiates a `renderContext`. Allocates `store` based on `contextKeyMax`.
* **`WithRenderFunc(f func(any, []byte, ast.Node, Context) error) ContextOption`**: A functional option to set the custom render function executed by `Context.Render`.

### Renderers and Decorators

#### `Renderer[W any]` Interface
The primary contract for an AST renderer where `W` is the target writer type (e.g., `io.Writer`, `util.BufWriter`).
```go
type Renderer[W any] interface {
    Render(w W, source []byte, n ast.Node, opts ...RenderOption) error
    RenderStringSource(w W, source string, n ast.Node, opts ...RenderOption) error
}
```

#### `NodeRenderer[W any]` Interface
Responsible for rendering individual `ast.Node` instances.
```go
type NodeRenderer[W any] interface {
    Render(w W, source []byte, n ast.Node, entering bool, rc Context) (ast.WalkStatus, error)
}
```

#### `NodeRendererFunc[W any]`
A function adapter that allows standard Go functions matching the `NodeRenderer.Render` signature to act as `NodeRenderer` instances.
```go
func NodeRendererFunc[W any](
    f func(w W, source []byte, n ast.Node, entering bool, rc Context) (ast.WalkStatus, error),
) NodeRenderer[W]
```

#### `NodeRendererDecorator[W any]`
A functional decorator pattern used to wrap existing `NodeRenderer` implementations:
```go
type NodeRendererDecorator[W any] = func(next NodeRenderer[W]) NodeRenderer[W]
```

### Configuration and Extensions

#### `Config[W any, C any]`
Holds configuration state, including maps of node renderers, node decorators, and extensions.
* **`nodeRenderers`**: `map[ast.NodeKind]NodeRenderer[W]` – Maps AST node kinds to their specific renderers.
* **`nodeRendererDecorators`**: `map[ast.NodeKind]NodeRendererDecorator[W]` – Maps AST node kinds to decorator functions.
* **`extensions`**: `[]Extension[C]` – List of renderer extensions.

#### `Option[C any]` & `NewOptionFunc`
Interface for configuring format-specific options applied to target configuration type `C`.
```go
type Option[C any] interface {
    SetFormatOption(*C)
}
```

#### Functional Configuration Helpers
* **`WithNodeRenderers[W, C](nodeRenderers map[ast.NodeKind]NodeRenderer[W]) Option[C]`**: Copies given renderers into the `Config`.
* **`WithNodeRenderer[W, C](kind ast.NodeKind, nodeRenderer NodeRenderer[W]) Option[C]`**: Sets a single node renderer for a node kind.
* **`WithNodeRendererDecorators[W, C](decorators map[ast.NodeKind]NodeRendererDecorator[W]) Option[C]`**: Applies decorators to specific node kinds. If a decorator already exists for a kind, the new decorator wraps the existing one.
* **`WithNodeRendererDecorator[W, C](kind ast.NodeKind, decorator NodeRendererDecorator[W]) Option[C]`**: Applies a decorator to a specific node kind.
* **`WithExtensions[W, C](ext ...Extension[C]) Option[C]`**: Registers extensions into the `Config`.

#### `Extension[C any]` Interface
Represents a renderer extension that supplies additional configuration options.
```go
type Extension[C any] interface {
    RendererOptions(*C) []Option[C]
}
```

## The Execution Engine: `Helper` & `HelperBuilder`

### `HelperBuilder[W, C]`
Provides a fluent builder pattern to construct a `Helper[W, C]`.

```go
builder := &HelperBuilder[W, C]{}
builder.Options(opts...).
    OnBeforeRender(func(w W, source []byte, n ast.Node, rc Context) error { ... }).
    Build()
```

### `Helper[W, C]` Struct
`Helper` provides the standard implementation of `Renderer[W]`. It handles configuration initialization, extension resolution, context binding, and AST walking.

#### Fields
* `config C`: Format-specific configuration object.
* `options []Option[C]`: Registered format options.
* `nodeRenderers []NodeRenderer[W]`: Slice of node renderers indexed directly by `ast.NodeKind`.
* `initSync sync.Once`: Ensures one-time initialization of `nodeRenderers` and extensions.
* `onBeforeRender func(w W, source []byte, n ast.Node, rc Context) error`: Callback executed right before rendering begins.

## Detailed Walkthrough: How Rendering Works

When calling `Helper.Render(w, source, n, opts...)`:

```
┌─────────────────────────────────────────────────────────┐
│                      Helper.Render                      │
└────────────────────────────┬────────────────────────────┘
                             │
            1. Lazy Initialization (sync.Once)
                             │
          ┌──────────────────┴──────────────────┐
          │ - Apply Option[C] to Config         │
          │ - Load & Apply Extension options    │
          │ - Apply NodeRenderer Decorators     │
          │ - Populate nodeRenderers slice      │
          └──────────────────┬──────────────────┘
                             │
             2. Context & Pre-render Setup
                             │
          ┌──────────────────┴──────────────────┐
          │ - Process RenderOption (WithContext)│
          │ - Fall back to NewContext()         │
          │ - Run onBeforeRender hook if defined│
          └──────────────────┬──────────────────┘
                             │
                 3. AST Traversal (ast.Walk)
                             │
          ┌──────────────────┴──────────────────┐
          │ For each node (entering & leaving): │
          │ - Lookup renderer by n.Kind()       │
          │ - Execute NodeRenderer.Render(...)  │
          └──────────────────┬──────────────────┘
                             │
              4. Writer Cleanup / Error Check
                             │
          ┌──────────────────┴──────────────────┐
          │ - Call Flush() if supported by W    │
          │ - Call Error() if supported by W    │
          └─────────────────────────────────────┘
```

1. **Initialization (`sync.Once`)**:
   * Evaluates all registered `Option[C]` against configuration type `C`.
   * Unwraps extensions attached to `Config` via `getConfig[W, C]` reflection utility and applies extension options.
   * Builds the lookup slice `nodeRenderers` indexed by `ast.NodeKind` (allocated up to `ast.CurrentKindValue + 1`).
   * Applies any defined `NodeRendererDecorator` instances to wrapped node renderers.

2. **Context Resolution**:
   * Extracts context passed via `WithContext(ctx)`.
   * If no context is provided, instantiates a default context via `NewContext(WithRenderFunc(...))` with the helper's `renderFn`.

3. **Pre-render Hook**:
   * If `onBeforeRender` callback is registered, executes it before starting traversal.

4. **AST Traversal (`renderFn`)**:
   * Calls `ast.Walk` starting from node `n`.
   * For every node event (both `entering` and `leaving`), retrieves the renderer at `r.nodeRenderers[n.Kind()]`.
   * If found, calls `NodeRenderer.Render(w, source, n, entering, rc)`.

5. **Writer Post-processing**:
   * Checks if target writer `w` implements `interface{ Flush() error }` and flushes pending data.
   * Checks if target writer `w` implements `interface{ Error() error }` and returns any recorded internal error.

## Internal Helper Functions

### `getConfig[W any, C any](c any) *Config[W, C]`
Uses Go reflection (`reflect`) to extract the embedded or named `Config` field of type `Config[W, C]` from the generic configuration struct pointer `c`.
* **Panic Behavior**: Panics with `"Config field not found in the given type"` if `c` is not a non-nil pointer containing a struct field named `Config`.
