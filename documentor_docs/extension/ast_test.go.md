# Technical Documentation: `extension/ast_test.go`

## Overview

The `extension/ast_test.go` file contains unit tests for the extensions module of the Goldmark Markdown parser (`github.com/yuin/goldmark/v2`). Its primary purpose is to verify that the Abstract Syntax Tree (AST) nodes generated by various extension parsers correctly report their starting byte positions (`Pos()`) within the original Markdown source input.

---

## Package and Dependencies

* **Package**: `extension_test`
* **Imports**:
  * `testing`: Standard Go testing package.
  * `github.com/yuin/goldmark/v2/extension`: Provides extension parsers for Strikethrough, Tables, Footnotes, and Definition Lists.
  * `github.com/yuin/goldmark/v2/parser`: Core parsing interfaces and constructors.

---

## Shared Test Input

Both test functions in this file parse the following raw Markdown string (represented as a byte slice):

```markdown
~~strike~~

| a | b |
|---|---|
| c | d |

[^fn]: footnote

term
: definition

text [^fn] end
```

---

## Helper Function

### `newExtensionParser() parser.Parser`

Constructs and returns a new Goldmark parser configured with the four extension parsers required by the tests:

```go
func newExtensionParser() parser.Parser
```

#### Extensions Enabled:
1. `extension.NewStrikethroughParser()`: Parses strikethrough syntax (`~~text~~`).
2. `extension.NewTableParser()`: Parses Markdown tables.
3. `extension.NewFootnoteParser()`: Parses footnote definitions (`[^fn]: ...`) and references (`[^fn]`).
4. `extension.NewDefinitionListParser()`: Parses definition lists (`term\n: definition`).

---

## Test Functions

### `TestInlinePos(t *testing.T)`

Tests whether inline AST nodes created by extensions report accurate starting positions (`Pos()`) in the source text.

#### Workflow:
1. Parses the standard test Markdown input using `newExtensionParser()`.
2. Validates the byte offset position of the **Strikethrough** inline node:
   * Traverses to `n.FirstChild().FirstChild()` (the inline strikethrough element inside the first paragraph).
   * Verifies that `Pos()` equals `0`.
3. Validates the byte offset position of the **Footnote Reference** inline node:
   * Traverses to `n.LastChild().FirstChild().NextSibling()` (the second child node within the last paragraph).
   * Verifies that `Pos()` equals `84`.

If any position does not match the expected offset, `t.Error` is invoked with an error message.

---

### `TestBlockPos(t *testing.T)`

Tests whether block-level and container AST nodes created by extensions report accurate starting byte positions (`Pos()`) in the source text.

#### Workflow:
Parses the standard test Markdown input using `newExtensionParser()` and traverses the resulting AST to verify node positions:

1. **Table Structure**:
   * **Table** (`table`): Position `12`
   * **Table Header** (`tableHeader`): Position `12`
   * **1st Table Header Cell**: Position `13`
   * **2nd Table Header Cell**: Position `17`
   * **Table Body** (`tableBody`): Position `32`
   * **Table Row** (`tableRow`): Position `32`
   * **1st Table Body Cell**: Position `33`
   * **2nd Table Body Cell**: Position `37`

2. **Footnote Definition**:
   * **Footnote Definition** (`footnotedef`): Position `43`

3. **Definition List**:
   * **Definition List** (`defList`): Position `60`
   * **Definition Term** (`defList.FirstChild()`): Position `60`
   * **Definition Description** (`defList.LastChild()`): Position `65`

If any AST node reports an unexpected byte offset, `t.Error` is invoked with a message specifying the node type that failed the position check.
