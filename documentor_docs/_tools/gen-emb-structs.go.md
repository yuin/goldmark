# Technical Documentation: `_tools/gen-emb-structs.go`

## Overview

The `_tools/gen-emb-structs.go` file provides code generation functionality to embed structured data into Go binaries using a compact representation. It parses a JSON definition file containing struct types and record entries, and generates a corresponding Go source file containing static constants, fixed-size arrays, and index byte strings.

---

## Command Line Interface (CLI)

The functionality is exposed through the `embStructsSubCommand` entry point, which configures a command-line flag set named `emb-structs`.

### Flags

| Flag | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `-i` | String | Yes | Path to the source input JSON file. |
| `-o` | String | Yes | Path to the generated target Go output file. |
| `-b` | String | No | Optional Go build tag string (e.g., `//go:build <tag>`). |

### Failure Handling
If command-line argument parsing fails or if either `-i` or `-o` is left empty, the utility invokes `usage(cmd.Usage, err)` to display usage details and terminate execution.

---

## Input JSON Format

The generator expects a JSON file containing three top-level keys:

```json
{
  "prefix": "html5entities",
  "types": {
    "Name": "string",
    "CodePoints": "[]int",
    "Characters": "[]byte"
  },
  "data": [
    {
      "Name": "AElig", 
      "CodePoints": ["198"], 
      "Characters": ["0xc3", "0x86"]
    },
    {
      "Name": "AMP", 
      "CodePoints": ["38"], 
      "Characters": ["0x26"]
    }
  ]
}
```

### JSON Fields

1. **`prefix`** (`string`): A base string used to name all generated Go constants and variables.
2. **`types`** (`map[string]string`): Key-value pairs defining field names and their target Go types.
3. **`data`** (`[]map[string]any`): An array of objects representing individual struct entries. Attribute values in the JSON are formatted as strings or arrays of strings.

---

## Code Generation Logic

### Output Package and Headers

1. **Target Package**: Determined dynamically from the parent directory name of the specified output file (`-o`).
2. **Build Tags**: If provided via `-b`, a `//go:build <buildTag>` line is written at the top of the file.
3. **Generated Header**: Outputs `// Code generated by _tools; DO NOT EDIT.` followed by the `package <pkg>` declaration.
4. **Length Constant**: Outputs a constant reflecting the total number of records in `data`:
   ```go
   const _<prefix>Length = <number of data items>
   ```

---

### Type Processing

The generator iterates through each field defined in `types` and produces Go primitives depending on the Go type string:

#### 1. String Types (`"string"`)
For string fields, data is packed into a single concatenated string constant, accompanied by an index string containing byte lengths encoded as hexadecimal escape sequences (`\xNN`).

* **Data Constant**:
  `const _<prefix><Field> string = "<Value1><Value2>..."`
* **Index Constant**:
  `const _<prefix><Field>Index string = "\x<Len1>\x<Len2>..."`

#### 2. Slice Types (`"[]<type>"`)
For slice fields (types starting with `[]`), elements across all entries in `data` are flattened into a single fixed-size array variable. An index string encodes the number of elements per record as hexadecimal escape sequences (`\xNN`).

* **Data Variable**:
  `var _<prefix><Field> = [...]<ElementType>{<Item1>, <Item2>, ...}`
* **Index Variable**:
  `var _<prefix><Field>Index string = "\x<Count1>\x<Count2>..."`

#### 3. Scalar / Other Types
For single primitive scalar types, data entries are written to a fixed-size Go array without a separate index string.

* **Data Variable**:
  `var _<prefix><Field> = [...]<Type>{<Value1>, <Value2>, ...}`

---

## Code Execution Flow

1. Parse CLI flags (`-i`, `-o`, `-b`).
2. Read the source JSON file from `-i` using `os.ReadFile`.
3. Unmarshal JSON contents into `map[string]any`.
4. Create the target file at `-o` using `os.Create`.
5. Extract the target directory name to infer package name `pkg`.
6. Write build tags (if specified), auto-generated warning, package name, and length constant `_<prefix>Length`.
7. Iterate over `types`:
   - Inspect type prefix (`string`, `[]`, or standard scalar).
   - Iterate over `data` to extract and construct data arrays/constants and companion hex index strings.
8. Output formatted strings to the output file handle and close the file.
