# Technical Documentation: `_tools/gen-unicode-case-folding-map.go`

## Overview

The `_tools/gen-unicode-case-folding-map.go` file is a Go utility tool designed to fetch the Unicode character `CaseFolding.txt` mapping file from `unicode.org` for a specified Unicode version, parse its contents, filter for specific case-folding classes, and generate an indented JSON output file. 

The resulting JSON output is structured to serve as input data for an `emb-structs` subcommand.

---

## Command-Line Flags

The entry point for this utility is the `unicodeCaseFoldingMapSubCommand(args []string)` function, which parses flags using Go's `flag.FlagSet`.

| Flag | Type | Default | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `-o` | `string` | `""` | **Yes** | Defines the target file path where the generated JSON data will be written. |
| `-u` | `string` | `"15.0.0"` | No | Specifies the Unicode standard version to download from `unicode.org`. |

### Execution Usage

```text
Usage of unicode-case-folding-map:

  Generate input JSON data for emb-structs subcommand from unicode.org
```

---

## Data Structures

### `caseFolding`

An internal struct used while processing individual lines of the Unicode mapping file:

```go
type caseFolding struct {
    Class byte
    From  rune
    To    []rune
}
```

* **`Class`**: Holds the single-character status/class code of the mapping (e.g., `'C'`, `'F'`, `'S'`, `'T'`).
* **`From`**: The source character code point parsed as a Go `rune`.
* **`To`**: A slice of destination character code points (`[]rune`) that `From` folds into.

## Workflow & Logic

```
   +-------------------------------+
   | Parse Flags (-o, -u)          |
   +---------------+---------------+
                   |
                   v
   +-------------------------------+
   | HTTP GET CaseFolding.txt      |
   | from unicode.org              |
   +---------------+---------------+
                   |
                   v
   +-------------------------------+
   | Parse line-by-line:           |
   | - Strip comments & whitespace |
   | - Filter for 'C' and 'F'      |
   | - Parse Hex code points       |
   +---------------+---------------+
                   |
                   v
   +-------------------------------+
   | Build JSON Map Structure      |
   +---------------+---------------+
                   |
                   v
   +-------------------------------+
   | Serialize & Write File (0644) |
   +-------------------------------+
```

### 1. Flag Validation and Initialization
* Parses arguments via `cmd.Parse(args)`.
* Validates that `-o` is non-empty. If empty or if parsing fails, it invokes `usage(cmd.Usage, err)`.

### 2. Fetching Unicode Data
* Constructs the target URL:  
  `http://www.unicode.org/Public/<unicodeVersion>/ucd/CaseFolding.txt`
* Performs an HTTP GET request using `http.Get(url)`.
* If the request or body reading fails, an error message is printed to stdout and the program terminates with `os.Exit(1)`.

### 3. Parsing and Filtering
The tool parses the downloaded text line by line using `bufio.Scanner`:
1. **Comment and Empty Line Removal**: Lines starting with `#` or containing only whitespace are skipped. Anything after an inline `#` character is discarded.
2. **Field Tokenization**: Lines are split by the semicolon `;` character, and whitespace is trimmed from all parts.
   * `parts[0]`: Source hex code point (parsed to `From`).
   * `parts[1]`: Class identifier (first character assigned to `Class`).
   * `parts[2]`: Space-separated list of target hex code points (parsed into `To`).
3. **Class Filtering**: Only entries with a `Class` of `'C'` (Common case folding) or `'F'` (Full case folding) are processed. Entries with other classes (such as `'S'` or `'T'`) are skipped via `continue`.
4. **Data Transformation**:
   * `From` is formatted as a hexadecimal string with a `0x` prefix (e.g., `"0x0041"`).
   * `To` code points are converted into a slice of decimal string representations (e.g., `["97"]`).

### 4. JSON Generation & Output
Constructs a map (`embstructmap`) with the following structure:
* `"prefix"`: Fixed string `"unicodeCaseFolding"`
* `"types"`: Object specifying schema types:
  * `"From"`: `"rune"`
  * `"To"`: `"[]rune"`
* `"data"`: List of mapped objects containing `"From"` and `"To"` fields.

The data is marshaled into formatted JSON via `json.MarshalIndent(embstructmap, "", "  ")` and saved to the location specified by the `-o` flag with file permissions `0644`.

## JSON Output Format Specification

The output file generated by this utility conforms to the following structural format:

```json
{
  "prefix": "unicodeCaseFolding",
  "types": {
    "From": "rune",
    "To": "[]rune"
  },
  "data": [
    {
      "From": "0x61",
      "To": [
        "97"
      ]
    }
  ]
}
```

## Error Handling

* **Invalid Arguments / Missing Output Path**: Invokes `usage(...)` and exits depending on `cmd.Parse` rules.
* **Network / I/O Failures**: Prints error directly to stdout and exits via `os.Exit(1)`.
* **JSON Serialization Failure**: Triggers a `panic(err)`.
* **File Output Write Failure**: Triggers a `panic(err)`.
