# Documentation Guide: `extra_test.go`

## Overview

The `extra_test.go` file contains a suite of unit, integration, performance, and security tests for the **Goldmark** Markdown parser (`github.com/yuin/goldmark/v2`). 

This test suite covers specific edge cases, including:
- Windows-style newline rendering (`\r\n`)
- Code block trailing characters
- Security sanitization of malicious URLs (e.g., `javascript:` links with case variations or HTML entity references)
- ATX heading attributes parsing
- Contextual ID generation overriding
- Performance/stress testing for deeply nested labels, CDATA sections, processing instructions, HTML declarations, and HTML comments

---

## Build Constraints & Initialization

### Build Tag
```go
//go:build !goldmark_v1_attribute
```
The file includes a Go build constraint specifying that it should only be compiled when the `goldmark_v1_attribute` build tag is **not** set.

### Package & Environment Configuration
* **Package:** `goldmark_test`
* **Global Variable:** `testTimeoutMultiplier` (default: `1.0`)
* **`init()` Function:** Reads the environment variable `GOLDMARK_TEST_TIMEOUT_MULTIPLIER`. If present and valid as a 64-bit float, it updates `testTimeoutMultiplier` to adjust performance test execution thresholds.

## Helper Types & Functions

### `nowMillis() int64`
Returns the current Unix timestamp in milliseconds (`time.Now().UnixNano() / 1000000`). Used by performance test cases to measure execution duration.

### Custom ID Generators

#### `myIDGenerator`
Implements the parser's ID generator interface.
* **`Generate(_ []byte, _ ast.NodeKind) []byte`**: Always returns the byte slice `"my-id"`.

#### `testIDGenerator`
Implements the parser's ID generator interface.
* **`Generate(_ []byte, _ ast.NodeKind) []byte`**: Always returns the byte slice `"test-id"`.

## Test Functions Breakdown

### 1. File-Based Integration Tests

#### `TestExtras(t *testing.T)`
* **Purpose:** Runs external test cases defined in `_test/extra.txt`.
* **Configuration:** Instantiates a parser and HTML renderer configured with `html.WithXHTML()` and `html.WithUnsafe()`.
* **Execution:** Calls `testutil.DoTestCaseFile` passing command-line arguments parsed via `testutil.ParseCliCaseArg()`.

---

### 2. Formatting & Syntax Edge Cases

#### `TestEndsWithNonSpaceCharacters(t *testing.T)`
* **Purpose:** Verifies that code blocks ending with non-space characters parse and render accurately.
* **Source Input:** ` ```\na\n``` `
* **Expected Output:** `<pre><code>a\n</code></pre>\n`

#### `TestWindowsNewLine(t *testing.T)`
* **Purpose:** Ensures Windows-style carriage return and linefeed sequences (`\r\n`) are properly handled for both hard line breaks (trailing spaces and backslash breaks).
* **Cases Tested:**
  1. Trailing spaces line break: `"a  \r\nb\n"` $\rightarrow$ `<p>a<br />\nb</p>\n`
  2. Backslash line break: `"a\\\r\nb\r\n"` $\rightarrow$ `<p>a<br />\nb</p>\n`

#### `TestATXHeadingAttributes(t *testing.T)`
* **Purpose:** Validates that ATX headings correctly parse inline attributes into the AST node when `parser.WithAttribute()` is enabled.
* **Source Input:** `# Heading {#my-id .my-class custom="hello"}`
* **Assertions:**
  * First child node must be of kind `ast.KindHeading`.
  * Node must contain attribute `id` with value `"my-id"`.
  * Node must contain attribute `custom` with value `"hello"`.

---

### 3. Security Tests (URL Neutralization)

#### `TestDangerousURLStringCase(t *testing.T)`
* **Purpose:** Verifies case-insensitive detection and removal of dangerous schemes (such as `javascript:`) in link URLs.
* **Source Input:**
  ```markdown
  [Basic](javascript:alert('Basic'))
  [CaseInsensitive](JaVaScRiPt:alert('CaseInsensitive'))
  ```
* **Expected Output:**
  ```html
  <p><a href="">Basic</a>
  <a href="">CaseInsensitive</a></p>
  ```

#### `TestDangerousURLWithReferences(t *testing.T)`
* **Purpose:** Validates that dangerous URLs using HTML entity references or alternative syntax constructs are neutralized across links, autolinks, and images.
* **Cases Tested:**
  1. **HTML Entity Encoded Link:** `[click](&#106;avascript:alert(1))` $\rightarrow$ `<p><a href="">click</a></p>\n`
  2. **Autolink:** `<javascript:alert(document.domain)>` $\rightarrow$ `<p><a href="">javascript:alert(document.domain)</a></p>\n`
  3. **Image Source:** `![alt](javascript:alert(document.domain))` $\rightarrow$ `<p><img src="" alt="alt"></p>\n`

---

### 4. ID Generation & Context Tests

#### `TestAutogeneratedIDs(t *testing.T)`
* **Purpose:** Verifies heading ID generation using a custom generator (`myIDGenerator`) and suffixing for collision avoidance.
* **Source Input:** `# Title1\n## Title2`
* **Expected Output:**
  ```html
  <h1 id="my-id">Title1</h1>
  <h2 id="my-id-1">Title2</h2>
  ```

#### `TestParseContext(t *testing.T)`
* **Purpose:** Tests the resolution hierarchy of ID generators when `parser.ParseContext` is supplied.
* **Assertions Tested:**
  1. No context supplied $\rightarrow$ Uses default ID generator (`id="test-test"`).
  2. Context supplied without ID generator $\rightarrow$ Uses default ID generator (`id="test-test"`).
  3. Context supplied with custom `testIDGenerator` $\rightarrow$ Uses custom ID generator (`id="test-id"`).

---

### 5. Performance & Stress Tests

All performance tests execute with $N = 50,000$ repeated syntax elements. They skip execution if `testing.Short()` is set. Execution time must not exceed `5000 * testTimeoutMultiplier` milliseconds.

| Test Function | Input Construction | Target Syntax Tested |
| :--- | :--- | :--- |
| `TestDeepNestedLabelPerformance` | `strings.Repeat("[", 50000) + strings.Repeat("]", 50000)` | Deeply nested bracket labels |
| `TestManyProcessingInstructionPerformance` | `"a " + strings.Repeat("<?", 50000)` | Unclosed Processing Instructions |
| `TestManyCDATAPerformance` | `strings.Repeat("a <![CDATA[", 50000)` | Unclosed CDATA Sections |
| `TestManyDeclPerformance` | `strings.Repeat("a <!A ", 50000)` | Unclosed HTML Declarations |
| `TestManyCommentPerformance` | `strings.Repeat("a <!-- ", 50000)` | Unclosed HTML Comments |
